## 3. デザインコンセプト

### コンセプト：「まちの相談窓口。ものを、次へ。」

緑・葉・資源循環というチラシの印象を引き継ぎ、明るい生成イラストと、深い緑の読みやすい文字を組み合わせる。清潔感のある余白と素直な情報の並びで、個人にも法人・自治会にも相談しやすい印象をつくる。

### 色・文字・形

| 役割 | 色の候補 | 用途 |
| --- | --- | --- |
| 主色 | 深緑 `#155A3D` | ロゴ、主要見出し、電話ボタン |
| 補助色 | 若葉色 `#DDECCB` | セクション背景、品目のイラスト背景 |
| 基本背景 | 生成り `#FAF9F2` | ページ全体 |
| アクセント | やわらかな黄 `#F4D568` | 相談の呼びかけ、小さな強調 |
| 本文 | 墨緑 `#24382D` | 説明文、基本情報 |

- 日本語は読みやすいゴシック体を基本とし、候補はNoto Sans JP。数字は見分けやすく、電話番号には桁の幅が安定する指定を使う。
- 本文は16〜18px程度、行間は1.8程度を目安にする。見出しは短く、長い説明は段落に分ける。
- ボタンは丸みをつける。本文中の項目は細い区切り線で整理し、すべてを同じカードに詰め込まない。
- 黄・若葉色は背景や装飾に使い、文字とのコントラストを実装時に確認する。
- 葉の形、ゆるやかな曲線、循環を感じる線を控えめに使い、環境認証や公的機関のマークのように見せない。

### ファーストビュー

横幅いっぱいのイラストを背景に、上部〜中央の余白へキャッチコピーと電話導線を置く。下部に住宅・集合住宅・自転車・小型家電・金属資源が穏やかにつながる情景を描く。実在の所在地や作業現場を再現する絵にはしない。

PCは画面の高さを活かした大きな構成、スマートフォンはキャッチ・電話番号・受付時間・出張案内が最初の画面で把握できる高さを優先する。画像の上にも十分な無地部分を確保し、文字の読みやすさを守る。

### 4-4. ご相談から対応まで

以下は依頼文の内容をもとにした案内順。現地確認の要否や支払い方法など、未提供の運用条件は加えない。

1. **お電話でご相談**：品物・数量・所在地・気になる点を伺う。
2. **内容・条件を確認**：状態や運び出しの条件などを確認し、対応可否と費用をご案内。
3. **訪問日時を調整**：案内内容にご納得いただいたうえで、都合に合わせて調整。
4. **確認した内容に沿って対応**：具体的な作業内容は事前に確認する。

### 5-3. 文字・表示・管理

- ロゴの日本語表記、電話番号、営業時間、OGPの文字は正確に組版する。生成画像内の日本語文字に依存しない。
- OGPの主文は「悩んだら、まずお電話ください！」。サービス名と「不用品の回収・買取相談／関東エリア対応」を添える。小さな条件注記が必要になる無料訴求はOGPに詰め込まない。
- サイト本文の情報はHTMLで表示し、画像だけに持たせない。
- 画像欄に「品目・サービスのイメージイラストです」と表示する。実績欄の数字や文章と混同させない。
- 情報を補う画像の代替テキストは「小型家電のイメージイラスト」等。純粋な装飾は空の代替テキストとする。
- 生成原本とWeb用の軽量画像を区別する。生成日・プロンプト・用途・加工内容を`docs/GENERATED-ASSETS.md`に記録する。
- ロゴは単色・白抜き・小サイズでも確認し、循環記号や葉の細部がつぶれる場合は簡略化する。公開前に既存ブランドと紛らわしくないか確認する。

## 6. スマートフォンとアクセシビリティ

- ヘッダーは小さなロゴと電話導線を中心にし、メニューは必要最小限。開閉時はキーボード操作とフォーカスを確認する。
- 下部固定の電話ボタンには「電話で相談」「9:00〜20:00」を表示し、電話番号も読める形で置く。リンク先は`tel:09035304405`。
- 電話ボタンは発信画面を開く動作とし、受付完了の表示は出さない。
- 時間外も対応時間を明記した電話リンクとして扱う。未確認の折り返し・留守番電話対応は約束しない。
- 固定ボタンの高さと端末のセーフエリアに応じた余白を確保し、フッターやFAQの操作を隠さない。
- タップ領域は44px以上を目安に確保。本文は画像化せず、拡大しても読める構成とする。
- 320〜430px幅を含めて折り返しと横スクロールを確認。電話番号は途中改行を防ぎ、キャッチは自然な文節で改行する。
- 色だけでサービス分類や注意を伝えず、見出しと短い文を添える。
- スキップリンク、見出し階層、フォーカス表示、FAQの開閉操作を整える。
- アニメーションは控えめなフェード・小さな移動まで。自動カルーセルや強制的なスクロール演出は設けない。動きを減らす設定に対応する。
- 電話ボタンと大切な費用条件は、アニメーションやJavaScriptの実行を待たず表示する。

- 品目は`id / category / examples / image / note / publish`などの項目で管理する。確認前の項目を本文や検索用データへ出さない。
- 遺品整理は独立したサービスデータとして保持し、説明や範囲の更新時に他の回収サービスへ影響しない構成にする。
- 電話・会社情報・受付時間は単一データからヘッダー、本文、固定導線、SEOへ反映する。
